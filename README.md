# Able Dental website
Static site. Open index.html in VS Code with the Live Server extension.

Images to add (then replace each `<div class="sp">Photo</div>` in index.html with an `<img>`):
- images/office.jpg (hero)
- images/team/dentist.jpg
- images/services/xray.jpg, preventive.jpg, fillings.jpg, root-canal.jpg, extractions.jpg, dentures.jpg, implants.jpg, crowns-bridges.jpg, aligners.jpg, whitening.jpg, mouth-guard.jpg, sleep-apnea.jpg

Service pages: services/<name>.html (one per service). Edit the text and replace the Photo div with an <img> in each.
Shared styles: css/style.css.

Pages: index.html, services.html (all services), patient-info.html, services/<name>.html (one per service).
